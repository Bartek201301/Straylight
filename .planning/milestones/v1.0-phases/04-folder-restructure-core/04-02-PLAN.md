<objective>
Colocate route-specific components into private _components folders next to their pages, and move admin-only components from the shared components directory into admin route colocation.

Purpose: Components that serve a single route belong next to that route's page.tsx. This reduces the shared components directory to truly shared components only, making the codebase easier to navigate. The underscore prefix (\_components) tells Next.js to exclude these folders from routing.

Output: Route-specific components colocated via \_components folders; shared components directory contains only truly shared components.
</objective>
