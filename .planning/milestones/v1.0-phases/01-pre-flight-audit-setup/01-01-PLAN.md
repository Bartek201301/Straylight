   ```json
   "analyze": "cross-env ANALYZE=true next build",
   ```

<task type="auto">
  <name>Task 2: Configure bundle analyzer and Knip, then format codebase</name>
  <files>next.config.js, knip.json</files>
  <action>
1. Wrap next.config.js with bundle analyzer:
   - Add at top of file: `const withBundleAnalyzer = require('@next/bundle-analyzer')({ enabled: process.env.ANALYZE === 'true' });`
   - Change `module.exports = nextConfig;` to `module.exports = withBundleAnalyzer(nextConfig);`
   - Do NOT modify any existing config — only add the wrapper.

2. Create knip.json at project root with initial configuration. Start minimal — Knip auto-detects Next.js from package.json:

   ```json
   {
     "$schema": "https://unpkg.com/knip@5/schema.json",
     "ignore": [
       "src/app/**/loading.tsx",
       "src/app/**/error.tsx",
       "src/app/**/not-found.tsx"
     ],
     "ignoreDependencies": ["@types/*"]
   }
   ```

   Note: Knip's Next.js plugin handles entry points automatically. Only ignore Next.js convention files that static analysis might flag as unused.

3. Run a diagnostic Knip check (output is informational only — no fixes in this phase):

   ```bash
   npx knip --reporter compact 2>&1 | head -50
   ```

   Capture the output summary for the plan summary. Do not act on findings — dead code removal is Phase 2.

4. Run a diagnostic madge check:

   ```bash
   npx madge --circular --ts-config tsconfig.json src/ 2>&1 | head -30
   ```

   Capture circular dependency count. Do not fix — restructuring is Phase 4.

5. Format the entire codebase with Prettier to fix the 34 drifted files:

   ```bash
   npx prettier --write "src/**/*.{ts,tsx,js,jsx,json,css,md}" "*.{js,json}" --ignore-path .gitignore
   ```

   This is safe — Prettier only changes whitespace/formatting, never logic. Doing it now means all future diffs during the refactor are clean.

6. Verify formatting is clean:

   ```bash
   npm run format:check
   ```
   Should report 0 formatting issues.
