<objective>
Dynamically import the TipTap editor, dashboard tab components, and optimize font weight loading.

Purpose: The TipTap editor is ~2,400 LOC across 3 files with heavy dependencies (@tiptap/\*) and is only used on the write page. The dashboard page statically imports 4 tab components (722 LOC total) but only renders one at a time based on active tab. Dynamic importing both the editor and dashboard tabs reduces initial bundle for these routes. Reducing Sora font weights from 6 to the 3-4 actually used cuts font payload by ~40%.
Output: Write page with dynamically-imported editor, dashboard with dynamically-imported tab components, optimized font configuration.
</objective>
