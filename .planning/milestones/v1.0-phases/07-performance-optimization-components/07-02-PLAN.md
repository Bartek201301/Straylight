2. **Create `_components/` directory** if it doesn't exist: `mkdir -p src/app/(marketing)/{page}/_components/`
3. **Extract the client content:**
   - Create a new file in `_components/` (e.g., `AboutContent.tsx`, `LibraryPageContent.tsx`, `SuggestResourceContent.tsx`)
   - Move ALL the component content (including `'use client'`, hooks, state, imports) into this new file
   - The new file should have `'use client'` at the top and export the component as default
4. **Convert the page file to a server component:**
   - Remove `'use client'`
   - Import the content component from `./_components/`
   - Add `import { Metadata } from 'next'`

**For suggest-resource page specifically:** Research indicates it also has commented-out metadata. Search and restore.

After ALL 3 conversions, run `npm run build` to verify everything works.

**Important:** The extracted content component must have EXACTLY the same behavior as before. Do not modify any logic, styling, or structure -- only move code.
