This task has two phases: manual handling of high-risk barrel files, then automated cleanup of straightforward unused exports.

**Phase A — Manual barrel file cleanup:**

1. **src/lib/optimized-imports.ts** (55+ flagged exports):
   - Run `npx knip --reporter compact` and extract all unused exports from this file
   - For EACH flagged export, grep the codebase: `grep -r "exportName" src/ --include="*.ts" --include="*.tsx"`
   - Only remove exports with zero consumers
   - Pay special attention to exports that might be used via destructuring or aliased imports
   - After cleanup: `npm run build && npm run lint && npx tsc --noEmit`

2. **src/lib/api/index.ts** (barrel file with re-exports):
   - Grep for `from '@/lib/api'` (without subpath) to find barrel consumers
   - Grep for `from '@/lib/api/` (with subpath) to find direct submodule consumers
   - If barrel consumers exist: only remove re-exports that are not consumed via the barrel
   - If no barrel consumers: consider whether the barrel file itself can be deleted
   - After cleanup: `npm run build && npm run lint && npx tsc --noEmit`

**Phase B — Automated export cleanup:**

3. Run `npx knip --fix --fix-type exports,types` to auto-remove remaining unused exports and types
   - IMPORTANT: This modifies source files directly. Review changes with `git diff` before proceeding.
   - The --fix flag will NOT delete files or remove dependencies -- it only removes unused export keywords and type exports
   - After auto-fix: review `git diff --stat` to see which files were modified
   - Scan the diff for any suspicious removals (exports from barrel files, exports used in tests, etc.)

4. Run `npm run build && npm run lint && npx tsc --noEmit` to verify nothing broke

5. If the build breaks after --fix:
   - Use `git diff` to identify which removal caused it
   - Restore the specific export with `git checkout -- path/to/file` (only restore that one file)
   - Re-run build to confirm fix
   - Note the false positive in the summary

**Phase C — Duplicate exports:**

6. Review the 8 duplicate exports identified by Knip
   - For each duplicate: determine which export form (named vs default) is more commonly used
   - Remove the less-used form, keeping the more standard one
   - After cleanup: `npm run build && npm run lint && npx tsc --noEmit`
